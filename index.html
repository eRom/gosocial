GoSocial

A personal command-line tool that publishes my own content to my own accounts, from my own computer.

Uses YouTube API Services

What it does

GoSocial is a single-user tool run locally on macOS by its developer, Romain Ecarnot. It is not offered to the public and has no other users.

  • Uploads videos to my own YouTube channel.
  • Sets the title, description, tags, thumbnail, playlist and audience settings of those videos.
  • Reads my own channel information to confirm which channel is connected.
  • Prepares announcement posts for my other social accounts.

How it uses YouTube

GoSocial accesses YouTube only through the official YouTube Data API, after I sign in with Google OAuth and grant access. It uses the following endpoints: videos.insert, videos.update, thumbnails.set, playlistItems.insert and channels.list.

The OAuth token is stored only in the macOS Keychain of my computer. There is no server, no database and no analytics. No YouTube data is sent to anyone other than YouTube itself.

By using GoSocial, you agree to be bound by the YouTube Terms of Service. GoSocial's handling of data is described in its Privacy Policy, which references the Google Privacy Policy.
