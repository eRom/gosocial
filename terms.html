GoSocial is a personal command-line tool developed and used by Romain Ecarnot to publish his own content to his own accounts. It is not offered as a public service.

YouTube Terms of Service

GoSocial uses YouTube API Services. By using GoSocial, you agree to be bound by the YouTube Terms of Service.

Threads

GoSocial also publishes text posts to the developer's own Threads account through the Threads API (scopes threads_basic and threads_content_publish), and nothing else: it does not read feeds, replies or insights. The only items stored are the Threads app credentials and the access token, kept in the macOS Keychain of the developer's Mac, with no server, no database and no analytics. Running gosocial auth threads logout deletes the token from the Keychain, and access can also be removed in the Threads settings (Settings > Account > Website permissions). The page threads-callback.html only forwards the sign-in code to the local GoSocial process on 127.0.0.1 and stores nothing.

LinkedIn

GoSocial also publishes text posts, and a first comment on each post, to the connected LinkedIn member's own profile through the LinkedIn API (scopes openid, profile and w_member_social), and nothing else: it does not read feeds, connections, messages or analytics. The only items stored, in the macOS Keychain of the developer's Mac and nowhere else, are the app credentials (client ID and secret), the access token, its expiry date, the member identifier (urn:li:person) and the display name, with no server, no database and no analytics. Running gosocial auth linkedin logout revokes the token and deletes it from the Keychain, and access can also be removed in the LinkedIn settings (Settings > Data privacy > Permitted services). The page linkedin-callback.html only forwards the sign-in code to the local GoSocial process on 127.0.0.1 and stores nothing.
